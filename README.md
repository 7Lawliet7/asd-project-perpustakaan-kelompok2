## 2. Deskripsi Sistem

Aplikasi CLI berbasis Python untuk membantu petugas mengelola koleksi buku perpustakaan skala kecil. Sistem ini mendukung operasi CRUD (Create, Read, Update, Delete) serta pencarian dan filtering data. 

Pada Tahap 1 (Checkpoint UTS), data disimpan di memori RAM menggunakan struktur data **Array of Struct** (direpresentasikan sebagai `list` of `dict` di Python). Data bersifat *volatile* (tidak permanen) dan akan di-reset setiap kali program dihentikan. Pengembangan struktur data yang lebih kompleks (Linked List, Stack, Tree) akan dilakukan pada tahap berikutnya.
